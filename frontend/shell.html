Shell Sort - Time and Space Complexity

Best Case
O(n log n)
Nearly sorted input with good gap sequence
Worst Case
O(n^2)
Bad gap choices (e.g. powers of 2) degrade badly
Parallel (p threads)
O(n/p * gaps)
Each gap-subarray sorted independently per thread
Space
O(1)
In-place - only a temp var for insertion key

How it works: Shell Sort is a generalization of Insertion Sort. Instead of comparing adjacent elements, it compares elements separated by a gap. Starting with a large gap (e.g. N/2), it performs gap-insertion passes, then shrinks the gap each round until gap = 1 - the final pass is a regular insertion sort, but by then the array is nearly sorted so it completes quickly. The parallel version exploits the fact that for a given gap, each sub-sequence is independent - different threads sort different sub-sequences simultaneously.
