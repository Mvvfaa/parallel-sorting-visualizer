Bubble Sort — Time & Space Complexity

Best Case
O(n)
Already sorted — one pass with zero swaps needed
Average Case
O(n)
Random input requires roughly n²/4 comparisons
Worst Case
O(n)
Reverse-sorted input — every pair must swap
Odd-Even Parallel
O(n) phases
n odd+even phases, each O(n/p) with p threads
Space
O(1)
Fully in-place — only a temp variable for swap

How it works: Bubble Sort repeatedly walks through the array, comparing adjacent pairs and swapping them if out of order — larger values "bubble up" to the right. The parallel version uses the Odd-Even Transposition scheme: odd phases compare pairs at indices (1,2), (3,4)… and even phases compare (0,1), (2,3)… All pairs in the same phase are independent and handled by separate threads simultaneously. After at most n phases the array is guaranteed sorted. Bubble Sort is stable and in-place but impractical for large inputs compared to O(n log n) algorithms — its value is simplicity and educational clarity.
