How it works: Merge Sort recursively divides the array into halves until each subarray has one element. Then it merges adjacent sorted subarrays by comparing their elements and combining them in order. The parallel version exploits the fact that independent subarrays at the same recursion level can be merged simultaneously by different threads. With p processors, each level takes O(n/p) time, giving O(n log n / p) total parallel time. Merge Sort is stable (preserves relative order of equal elements) and has predictable performance.
